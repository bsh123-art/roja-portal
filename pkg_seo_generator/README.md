# SEO Generator for Joomla

This package adds a Joomla content plugin that automatically creates article keywords and meta descriptions from the article title and content.

## Features
- Generates keywords by frequency analysis
- Uses title, content or both as the source
- Filters common words and allows custom stopword lists
- Saves generated metadata when articles are saved
- Optionally generates metadata on the fly for frontend rendering
- Supports robots meta and Google Search Console verification tags

## Installation
1. Upload the package file in Joomla Administrator.
2. Go to Extensions -> Plugins.
3. Enable the Content - SEO Generator plugin.
4. Adjust the keyword and blacklist settings as needed.

## Notes
The implementation is intentionally lightweight and designed to be easy to extend for more advanced SEO workflows.
