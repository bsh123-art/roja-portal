# Panduan Instalasi ROJA Comments v3 untuk Pemula

## 1. Siapkan file install
Pastikan Anda sudah punya file berikut:
- pkg_v3.zip

File ini bisa Anda temukan di folder project Anda atau hasil export package akhir.

## 2. Login ke admin Joomla
1. Buka alamat admin Joomla Anda.
2. Masukkan username dan password admin.

## 3. Install extension
1. Di menu kiri, masuk ke System.
2. Pilih Install.
3. Klik Extensions.
4. Klik tombol Upload Package.
5. Pilih file pkg_v3.zip.
6. Tunggu sampai proses instalasi selesai.

## 4. Aktifkan plugin
1. Masuk ke Extensions → Plugins.
2. Cari plugin dengan nama: Content - ROJA Comments v3.
3. Ubah status plugin menjadi Enabled.
4. Jika plugin masih tidak muncul, pastikan instalasi selesai tanpa error.

## 5. Cek konfigurasi
1. Buka Components → ROJA Comments v3 → Options.
2. Pastikan opsi berikut aktif:
   - Enable Comments = Yes
   - Allow Guest Comments = Yes atau sesuaikan kebutuhan
   - Moderate New Comments = Yes jika ingin moderasi manual
3. Simpan pengaturan.

## 6. Uji halaman artikel
1. Buka halaman artikel di frontend Joomla.
2. Scroll ke bawah artikel.
3. Anda akan melihat form komentar.
4. Coba tulis komentar sederhana.
5. Klik tombol Send Comment.

## 7. Jika komentar tidak muncul
Periksa hal-hal berikut:
- Plugin ROJA Comments v3 aktif
- Component ROJA Comments v3 terinstall
- Artikel ada di kategori yang diizinkan
- Cache Joomla sudah dibersihkan
- Tidak ada error 500 saat membuka artikel

## 8. Jika terjadi error 500
Lakukan langkah berikut:
1. Nonaktifkan plugin ROJA Comments v3.
2. Clear cache Joomla.
3. Install ulang package terbaru.
4. Aktifkan lagi plugin.

## 9. Apa yang bisa dilakukan pengunjung
- menulis komentar baru
- membalas komentar
- menyukai komentar
- melaporkan komentar
- melihat komentar terbaru atau paling banyak disukai

## 10. Selesai
Setelah langkah di atas berhasil, fitur komentar ROJA Comments v3 sudah aktif di website Joomla Anda.

Jika Anda masih bingung, Anda bisa meminta bantuan admin teknis untuk proses instalasi di sisi hosting atau server.
